Local Cache & Reconnection Resumption

@Composable ChatScreen

Mobile Problem: Opening a chat app while waiting for a game match shouldn't show a blank loading spinner. Network dropped during subway commutes or Wi-Fi handoffs shouldn't lose messages.

Architecture Solution: The Android client queries the local SQLite/Room database instantly on cold launch. Concurrently, the client sends a SyncMessages(last_message_id) request to retrieve any messages sent while offline or disconnected.

{ } Key Compose & Android Components:
  • LazyColumn(reverseLayout = true) for smooth inverted chat history scrolling
  • Room Database + Paging 3 for instantaneous offline reads
  • WebSocket client with exponential backoff & auto-resume token
